# Производство «Кёнел» продаётся

Адаптивный одностраничный сайт закрытой продажи действующего производства фасадных комплектующих.

## Локальный запуск

```powershell
python -m http.server 4173
```

После запуска открыть `http://localhost:4173/`.

Контактный номер задаётся константой `PHONE` в `site.js`.
